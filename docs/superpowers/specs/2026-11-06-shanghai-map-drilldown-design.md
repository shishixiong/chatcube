# 上海地图下钻（map_card · 省级下钻第一期）

> 设计稿：`docs/shanghai-map-drilldown.html`（自包含，浏览器直接打开）
> 数据：`entry/src/main/resources/rawfile/map/shanghai_districts.json`
> 落地：`MapCard` / `MapAtlasProvinceCard` / `ShanghaiMapStage` / `ShanghaiMapData` / `ShanghaiAtlasCopy`

## 一、为什么做

`map_card` 原来的全国图里，点任何一个省都只是把资料卡换一张：全国图不变，孩子看到的永远是「一个色块 + 一张卡」。
上海是最适合先做深的一个：面积最小、区最少（16 个）、区名孩子听得多（黄浦江、浦东、崇明），
而且它的形状本身就是「长江口 + 一座岛」，讲地理一次能讲三件事。

所以第一期只解决一件事：**点上海，把地图册翻到里面一页**。翻页不是新页面：
同一张卡片、同一个位置，只有地图和资料卡换了内容。孩子不会「迷路」，老师也不用重新讲一遍怎么玩。

## 二、交互定案

1. **入口只有一个**：全国图上点「上海」。它同时把上海记进「已探索」，和其它 33 个省一视同仁。
2. **下钻页的页眉**：课名变成「上海地图小课堂」，地图册页眉变成「上海 · 16 个区」，
   左边一直是「‹ 返回全国」。
3. **返回有两条路**：点页眉的「‹ 返回全国」，或在翻回全国后点别的省。下钻页本身不显示邻省，
   所以「在下钻页直接点江苏」这条设计稿里的设想没有落地——地图上只有区，没有可点的省。
   时间线内联的小图没有页眉，所以在小图左上角补一个同样语义的「‹ 返回全国」小药丸。
4. **进度口径不变**：一节课的进度单位始终是「34 个省级行政区」。「看过几个区」是二级进度，
   只在地图册页脚显示（`看过 3 / 16`），不进主进度、不影响「我学会了」的解锁条件
   （仍是 `canSubmit = exploredCount > 0`，与本次改动前一致）。
5. **区级只出现在讲解课**：`map_quiz` / `map_puzzle` 仍然只考 34 个省。两套行政区划层混进练习，
   会让「星星按什么发」说不清。
6. **命中判定复用射线法**：区级 path 与省级 path 同为 `M/L/Z` 纯多边形，
   直接调 `pointInProvince`；没有第二条几何管线，也没有第二份坐标系。
7. **时间线回看**：历史 payload 里 focus 是上海时，资料卡仍有「再看看 16 个区」入口，
   可以翻到上海页，但 `interactive: false`——看得到、点不动，不产生新进度；小图左上角保留返回键。

## 三、数据

- 源：阿里 DataV `310000_full.json`（16 个区的真实边界，含崇明、长兴、横沙与浦东离岛）。
- 投影：等距圆柱，经度按 31.2° 纬度压缩（cos ≈ 0.855），与 `china_provinces.json` 同一套约定，Y-down。
  输出 `viewBox="0 0 1000 1007.4"`，和全国图用同一个「1000 宽」基准。
- 抽稀：RDP，主轮廓每环最多 260 点、小岛 60 点，误差约 60 m。共 25 环 / 2714 顶点 / 43 KB。
- `short`：去掉「区」/「新区」→「黄浦」「浦东」「崇明」，给印章和地图标签用。
- `center`：取 GeoJSON 的 `centroid`（面积质心），16 个全部验证过落回本区，用作区名标签锚点。
- 小地名（`places[]`）：78 个，全部用同一套投影换成地图坐标，再逐点用射线法验证落在**本区**里；
  崇明的长兴、横沙是多环里的独立岛环，点必须落进那一个环。`x/y` 是地图坐标，**不要手改**。
  三层配额：tier 1 每区恰好 1 个（资料卡「地标」），tier 2 每区最多 4 个，其余进 tier 3。
- 落盘位置：`entry/src/main/resources/rawfile/map/shanghai_districts.json`（43 KB，随包发布），
  与 `ChinaMapData` 一致：`getRawFileContentSync` + `TextDecoder` + 模块级缓存。
- 生成脚本（`build-shanghai-districts.py` / `build-place-layer.py`）留在设计工程里，本次没有随包引入；
  改数据要回到脚本重跑，不要在 JSON 上手改坐标。

## 五、地图的读法（下钻页）

- **不要一次给 16 个区名**。市中心 7 个区（黄浦、徐汇、长宁、静安、普陀、虹口、杨浦）加起来还没崇明大，
  全标出来就是一团墨。默认只标 9 个大区，选中谁就标谁；放大到 1.55× 以上，16 个全出现。
- **标签压在纸上，不压线**。文字先描一圈纸色再填字，跨区界也读得清。
- **标签字号按屏幕 vp 定**（12→18），不按地图坐标。小舞台 fit≈0.35 时，12 个地图单位只剩 4 px，
  孩子根本看不清；按屏幕定字号，同一份数据在手机和 sheet 上一样读。
- **选中区最后画界线**，不会被邻区盖住；线宽按屏幕 vp 定（普通 1 / 看过 1.6 / 选中 2.2），放大不跟着变粗。
- **区名标签互相让位**：1.55× 时「静安 / 虹口 / 杨浦」的质心相距不到 14 vp，
  给固定的上下/左右错身量（只动字，不动锚点）。**地名标签再让区名**：外滩/鲁迅公园这类
  tier 1 地名离区名不到一行字时，把地名推到区名的上一行或下一行（圆点仍在真实坐标）。
- **点空白 = 取消选择**，回到「选一个区开始」。
- **小地名分三级给**：默认每个区只浮出一个小地名（黄浦→外滩、浦东→陆家嘴、松江→佘山），
  选中的区亮着，其余区降一档（往纸色里混 55%，颜色关系不变，只是不抢眼）。
  再放大到 1.7× 出第二层、2.6× 出第三层，一共 78 个真地名。资料卡「里面还有 外滩 +4」和地图
  用**同一条** `placeTierZoom` 判定——卡片说几个，地图上就是几个。
- 指北针与比例尺保留：比例尺给出「这根线大概多少米」，上海这一页才讲得清崇明有多大。
- **拖动与缩放只有一个算式**：`fitScale` 把「设计稿坐标 → 屏幕像素」一次算完，
  图形按原坐标画、`zoom` 进同一个比例；可拖范围按 `clampPan` 夹取，1× 时整张图在框里（拖不动是对的），
  放大后图边不出舞台，连滚多下也不会把上海推出画框。

## 七、下一个省怎么接

第一期刻意把「省级 → 区县」写成**一个数据文件 + 一个数据类**的组合，而不是写死上海：

```
rawfile/map/
  china_provinces.json
  shanghai_districts.json      ← 文件名 = 省份拼音 + districts
```

接第二个省只需要：

1. 用同一个脚本参数化（`--code 320000 --name 江苏`）生成 `jiangsu_districts.json`；
2. 把 `MapCard` 里 `SHANGHAI_PROVINCE_ID` 的判断换成一张表 `DRILLDOWN_PROVINCE_IDS: string[]`；
3. 页眉文案从 `buildShanghaiAtlasTitle` 泛化成 `buildSubUnitAtlasTitle(provinceName, unitName, total)`。

**不太适合下钻的省要先想清楚**：江苏 13 个地级市（不是区）、新疆有州和地区、直辖市是区、
特别行政区是堂区——「下一级叫法」不同，标签和文案得跟着变（所以文案函数都带 `unitName`）。
真正该在第二期做的是**先把「下一级」抽象成一个 `SubUnit` 概念**，再挑一个地级市省做验证。

## 八、刻意没做的事

- **不做「上海专题课」**：现在它是同一节课里的一层，不另起星星、不另算课时。
- **不做区级练习**：见第二节第 5 条。
- **不做榜单/进度环**：`map_card` 一直是「看完就能继续」，加进度可视化会把讲解课变成打卡。
- **不做地图上直接点区名**：标签只画不接收点击，点击一律走图形命中，避免「点到字没点到区」的误判。
- **不引入新颜色**：全部沿用 `MapAtlasTokens` 的暖纸令牌。
- **不画示意图水系**：设计稿里的长江口 / 黄浦江折线是按旧坐标系手绘的，采样点会落进崇明和浦东的区界里，
  和 1000×1007.4 的真实区界对不上；这一版宁可不画，也不把黄浦江画到岛上去。
- **不做小地名的点击与卡片**：小地名此刻只是「区里有什么」的提示，点上去不跳、不存进度。
